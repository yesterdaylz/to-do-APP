# 柠檬Todo🍋

一个简易的 Android 待办（To‑Do）app，使用 Kotlin语言。

---

## 简介

本项目是一个本地离线的待办管理与专注计时应用。主要功能包括待办的增删改查、到期提醒通知、番茄钟/计时记录、随机名言、多用户本地登录与简单的统计展示。主要用于个人学习、侧重于功能实现，不供学习参考，不供使用。

---

## 主要功能

- 待办事项：创建、查看、编辑、删除、置顶、分类、提前标记完成（长按）
- 通知提醒：待办定时提前与到期截止提醒，发送本地通知，支持自动标记完成
- 番茄钟 / 计时：专注计时与时间记录保存，支持暂停继续、正计时、倒计时、番茄三模式切换、背景音乐播放、完成提示音播放
- 统计：最近七日柱状图类统计（基于本地记录）和当天专注次数与时间展示
- 用户：本地登录/注册（多用户）、用户信息存储
- UI：支持深色模式与中英切换
- 随机名言：通过一言（hitokoto）API 拉取每日随机名言并展示
- 支持本地封面图选择与显示（内部存储）
- [更新日志](UpdateLog.md)
